Read-depth labels:

- `METADATA ONLY`: only bibliographic metadata was inspected. No mechanism, evaluation, or result is inferred. Such cells say `not verified from full text`.

## Theme Summary

**1. CXL pooling and arbitration**

- Core rows: `pond2023`, `directCXL2023`, `hpcPool2022`, `myCxlPool2025`, and `faiCxl2025`.
- `faiCxl2025` is the only reviewed row that directly evaluates switch-side arbitration for a CXL memory pool; `myCxlPool2025` is a software alternative that deliberately avoids a hardware switch. `pond2023`, `directCXL2023`, and `hpcPool2022` motivate pooling and contention but do not isolate the arbiter.
- Qualified adjacent row: `contentionCache2024` uses weighted fair queuing to arbitrate demand and prefetch requests at the far-memory node, not at a CXL switch. Its reported 10-13% total IPC gain is an abstract-level result.
- Background context: `cxlIntro2024`, `demystify2023`, and `topology2024`. Use these for CXL semantics and topology dependence, not for scheduler PPA.

**2. Fairness and QoS lineage**

- Core rows: `stfm2007`, `atlas2010`, `tcm2010`, `bliss2014`, and `faiCxl2025`.
- Network/QoS lineage: `gupta1999` for round-robin crossbar arbitration, `wfqSort2008` for hardware WFQ sorting, and `wfqArch2012` for a complete FPGA WFQ datapath. `rixner2000` is useful for DRAM locality scheduling but does not address fairness.
- The strongest hardware-cost precedent is `bliss2014`: it reports synthesized 32 nm area and critical-path results. It is not a CXL study. `faiCxl2025` carries the fairness mechanism into a CXL switch but reports only estimated hardware cost.

**3. CXL-specific scheduling and interleaving**

- Primary row: `faiCxl2025`, which combines 64 B weighted interleaving with adaptive priority scheduling.
- Switch and system context: `cxlDmsim2026` for a parameterized CXL switch model and measured switch latency; `myCxlPool2025` for a switch-free software pooling design; `topology2024` for topology-dependent performance.
- Adjacent CXL concerns: `contentionCache2024` for FAM-side demand/prefetch prioritization, `cxlInterplay2025` for interference, `redit2025` for fabric-side coherence metadata, `demystify2023` for real-system memory behavior, and `rethinkingPool2025` for coherence-management framing.
